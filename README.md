## 📌 Project Overview

This project is an Employee Management System developed as part of the Orange Coding Academy training.

The system simulates a real company environment where HR and employees can manage daily activities, requests, meetings, tasks, feedback, and employee information.

The project was developed collaboratively by a team of six members.

---

## 🎯 Project Goals

- Manage employees and their information.
- Provide different functionalities for HR and employees.
- Manage leave requests.
- Manage meetings.
- Create and manage tasks.
- Provide feedback.
- Display company policies.
- Manage employee profiles.
- Provide dashboards with important information.

---

## 👥 User Roles

### HR

HR users can:

- View the HR Dashboard.
- View employee information.
- Manage leave requests.
- Create and manage meetings.
- Create and manage tasks.
- Accept or reject requests.
- View company policies.
- Manage their profile.

### Employee

Employees can:

- View their dashboard.
- View and edit their profile.
- Submit leave requests.
- View leave request status.
- View meetings.
- View assigned tasks.
- Update task status.
- Submit feedback.
- View company policies.

---

## ✨ Main Features

### 🔐 Login System

Users can log in using their email and password.

The system identifies the user's role and redirects them to the appropriate dashboard.

### 👤 Profile Management

Users can view and edit their personal information, including:

- Name
- Phone
- Address
- Profile image
- Password

### 🏖️ Leave Requests

Employees can submit leave requests.

HR can review, accept, or reject requests.

### 📅 Meeting Management

HR can create meetings, while employees can view their meetings and related information.

### ✅ Task Management

HR can create and assign tasks to employees.

Employees can view their assigned tasks and update their status.

### 💬 Feedback

Users can submit feedback through the system to improve communication within the company.

### 📜 Company Policy

Employees can view company policies and important company information.

### 📊 Dashboard

The dashboard provides an overview of important information such as:

- Number of employees
- Number of tasks
- Leave requests
- Meetings
- Other system statistics
